## 推荐机位

- **侧面**（矢状面）：身体一条线与肘角清晰  
- 手机竖屏，低支架或靠墙，约与肩同高侧对身体  
- 需看到：肩、肘、腕、髋、踝  

> **与 PRD FR-002 的取舍**：PRD 写「俯卧撑默认正面」。MVP 规则（身体一线、肘深）依赖侧面几何，故机位定为 **side**。正面「肘外展约 45°」留作 P2，启用时另补规则与矩阵。

## 校验规则

| 规则 ID | 关节 (a-b-c) | 条件 | 容差 | 阶段 | 严重度 | 提示文案 |
|---------|--------------|------|------|------|--------|----------|
| elbow-depth | 肩-肘-腕 | 肘角 < 110° | 10° | bottom | warning | 手臂未弯到位，胸口再靠近地面 |
| body-line | 肩-髋-踝 | 角 ≥ 170° | 10° | all | error | 臀部翘起或下沉，保持身体一条直线 |

### 判定说明（MVP）

- **肘深**：目标肘角 &lt; 110°；容差 10° → 仅肘角 **≥ 120°** 才报未弯到位。  
- **身体一线**：肩-髋-踝夹角理想近 180°；容差 10° → 仅 **&lt; 160°** 才报（塌腰或撅臀）。全程评估。  
- **反馈缓冲**：同深蹲 — 进入/解除防抖约 800ms，冷却 3s（`feedback.ts`）。

### 依据与取舍

| 规则 | 文献/行业锚点 | 本产品取舍 |
|------|----------------|------------|
| elbow-depth | NASM：胸口接近地面；肘≈90° 是理想粗代理 | 端侧肘角常偏「撑开」；v0.2.1 将目标放到 &lt;110°（≥120° 才报），减少「降得不够低」误杀 |
| body-line | NASM / NSCA：头到脚跟一条线，髋不塌不撅 | 肩-髋-踝 ≥170°（报错 &lt;160°）；不区分塌/撅，统一文案 |
| （未做）肘外展 | 教练常要求肘相对躯干约 45° | P2 + 正面机位 |

## 相位定义

由**肘角**（两侧均值）驱动，状态机同深蹲语义：

| 相位 | 进入条件（肘角，连续 5 帧） |
|------|---------------------------|
| stand（撑起/顶） | > 160° |
| descend | 160° → 120° 下降中 |
| bottom | < 120° |
| ascend | 120° → 160° 上升中 |

## Rep 计数

- 计 1 rep：`stand` → `descend` → `bottom` → `ascend` → `stand`
- bottom 阶段触发 `elbow-depth` → 该次 **不计入**（rejected / depth_fault）
- 从未进入 bottom → 半程不计（rejected / shallow），文案：「降得不够低，未计入次数」
