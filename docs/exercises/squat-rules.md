# 深蹲 — 校验规则与关键帧

> AI Agent：实现 `packages/core/exercises/squat.ts` 时必须与本文件一致。

## 推荐机位

- **侧面**（左侧或右侧均可；髋、膝、踝入画即可，不必顶满站位框）
- 手机竖屏，腰高侧放，约 1.2–1.8m，与地面约 15–30° 角
- 需看到：肩、髋、膝、踝

## 校验规则

| 规则 ID | 关节 (a-b-c) | 条件 | 容差 | 阶段 | 严重度 | 提示文案 |
|---------|--------------|------|------|------|--------|----------|
| squat-depth | 髋-膝-踝 | 膝角 < 100° | 10° | bottom | error | 蹲得不够深，臀部再下沉一些 |
| knee-valgus-l | 髋-膝-踝（左） | 膝相对髋-踝线向内偏 | 35° | bottom | error | 左膝内扣，向外推开膝盖 |
| knee-valgus-r | 髋-膝-踝（右） | 膝相对髋-踝线向内偏 | 35° | bottom | error | 右膝内扣，向外推开膝盖 |
| torso-upright | 肩-髋 vs 竖直 | 前倾角 ≤ 45° | 10° | all | warning | 躯干前倾过多，挺胸收紧核心 |

### 判定说明（MVP）

- **深度**：目标膝角 &lt; 100°（平行蹲可计 rep）；容差 10° → 仅膝角 **≥ 110°** 才报不够深。
- **膝内扣（侧摄禁用）**：侧面入镜时膝前移会造成「内扣」幻觉，**侧摄 MVP 评估恒为不触发**；规则与阈值保留，待正面机位再启用。
- **躯干**：量的是 **肩-髋相对竖直的前倾角**（0°=直立），**不是**肩-髋-膝夹角（深蹲底部后者本就会变小）。理想 ≤45°；容差 10° → 仅前倾 **&gt;55°** 才 warning。正常侧蹲 20–40° 不报。
- **反馈缓冲**：错误需持续约 **800ms** 才上条；同规则确认后 **3s** 内不重复播报（见 `feedback.ts`）。

## 相位定义

| 相位 | 进入条件（膝角，连续 5 帧） |
|------|---------------------------|
| stand | > 160° |
| descend | 160° → 100° 下降中 |
| bottom | < 100° |
| ascend | 100° → 160° 上升中 |

## Rep 计数

- 计 1 rep：`stand` → `descend` → `bottom` → `ascend` → `stand`
- 若 `bottom` 阶段 `squat-depth` 触发（未达深度），该次 **不计入** rep
- **半蹲不计入**：未进入 `bottom`（膝角始终 ≥ 100°）的周期不产生有效 rep；回站时提示「蹲得不够深，未计入次数」

## Ghost 关键帧（归一化坐标，侧面）

实现时在 `packages/core/exercises/squat-keyframes.ts` 定义 5 帧：

1. `stand` — 直立
2. `descend_mid` — 下蹲至膝角约 120°
3. `bottom` — 膝角约 85°
4. `ascend_mid` — 起身中
5. `stand` — 回直立
