## 校验规则

| 规则 ID | 关节 (a-b-c) | 条件 | 容差 | 阶段 | 严重度 | 提示文案 |
|---------|--------------|------|------|------|--------|----------|
| squat-depth | 髋-膝-踝 | 膝角 < 100° | 10° | bottom | error | 蹲得不够深，臀部再下沉一些 |
| knee-valgus-l | 髋-膝-踝（左） | 膝相对髋-踝线向内偏 | 35° | bottom | error | 左膝内扣，向外推开膝盖 |
| knee-valgus-r | 髋-膝-踝（右） | 膝相对髋-踝线向内偏 | 35° | bottom | error | 右膝内扣，向外推开膝盖 |
| torso-upright | 肩-髋 vs 竖直 | 前倾角 ≤ 45° | 10° | stand | warning | 躯干前倾过多，挺胸收紧核心 |

### 判定说明（MVP）

- **深度**：目标膝角 &lt; 100°（平行蹲可计 rep）；容差 10° → 仅膝角 **≥ 110°** 才报不够深。
- **膝内扣（侧摄禁用）**：侧面入镜时膝前移会造成「内扣」幻觉，**侧摄 MVP 评估恒为不触发**；规则与阈值保留，待正面机位再启用。
- **躯干**：量的是 **肩-髋相对竖直的前倾角**（0°=直立），**不是**肩-髋-膝夹角。理想 ≤45°；容差 10° → 仅前倾 **&gt;55°** 才 warning。**仅 stand 相位**评估：下蹲底部自然前倾常达 45–65°，若在 bottom 也报会误伤正确深蹲并干扰计次手感。
- **反馈缓冲**：错误需持续约 **800ms** 才上条；确认后须再持续约 **800ms** 未触发才解除（防噪声闪绿）；同规则确认后 **3s** 内不重复播报（见 `feedback.ts`）。相位切换导致规则不适用时立即解除 latch。

### 依据与取舍（方案 A，2026-08-04）

> 本节说明「为什么是这些数」，**不改变上表阈值**。工程一致性靠 RULE-BOUNDARY；本节是产品/科学层签字。

| 规则 | 文献/行业锚点 | 本产品取舍 |
|------|----------------|------------|
| squat-depth | 常见「平行蹲」：大腿近平行地面；关节角文献表多落在更深区间（约 70°–90° 一带，角越小越深）。力量举要求髋纹低于膝，比平行更深。 | **消费级放宽**：目标 &lt;100°、≥110° 才报，允许略浅于严格平行仍可练。主路径「不够深」更多靠未进 bottom 的半蹲不计次；`squat-depth` 是强制 bottom 相位下的补强（见审计 §3.1）。 |
| knee-valgus-* | NASM 等：动态膝外翻宜**正面**观察，与 ACL 风险相关。 | **侧摄禁用**是正确工程决策（侧视膝前移易假阳性）。阈值保留供正面机位；启用时必须新做正面矩阵，禁止复用侧摄夹具。 |
| torso-upright | Schoenfeld / NSCA 综述：下蹲时一定前倾常不可避免；应避免变成有害腰屈代偿。无单一「55°」金标准。 | 度量用肩-髋相对竖直（不用肩-髋-膝）。**仅 stand** 报，避免误伤正确深蹲底部。45°+10° 容差是「站立弯腰」启发式，非脊柱安全刻度。 |

## 相位定义

| 相位 | 进入条件（膝角，连续 5 帧） |
|------|---------------------------|
| stand | > 160° |
| descend | 160° → 100° 下降中 |
| bottom | < 100° |
| ascend | 100° → 160° 上升中 |

## Rep 计数

- 计 1 rep：`stand` → `descend` → `bottom` → `ascend` → `stand`
- 若 `bottom` 阶段 `squat-depth` 触发（未达深度），该次 **不计入** rep
- **半蹲不计入**：未进入 `bottom`（膝角始终 ≥ 100°）的周期不产生有效 rep；回站时提示「蹲得不够深，未计入次数」
