# 标准动作 3D 示意素材（预渲染视频）

详情页播放预渲染循环片（解剖/肌群高亮风格），**不是**训练页半透明骨架 Ghost。

## 放置路径

`apps/mobile/assets/demos/<filename>.mp4`

接入代码：`apps/mobile/src/demoAssets.ts`（取消对应 `require` 注释后 Reload）。

## 规格建议

| 项 | 建议 |
|----|------|
| 编码 | H.264 + AAC（或无音轨） |
| 时长 | ≤ 15s，可无缝循环 |
| 画幅 | 1:1 或竖屏 9:16；白底为佳 |
| 体积 | 单条约 ≤ 8MB（自用可略放宽） |
| 内容 | 实体 3D 模型演示；可高亮发力肌群 |

## 已挂名（catalog.demoAsset）

| 动作 | 文件名 |
|------|--------|
| 深蹲 | `squat.mp4` |
| 俯卧撑 | `pushup.mp4` |
