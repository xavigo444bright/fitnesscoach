# App 信息架构、动线与开发计划

> 视觉：MLS Official App（OQ-009 / `design-system/fitness-coach/MASTER.md`）。  
> 功能：跟练 + 课表记训两套并存（OQ-008）、账号可游客（FR-100）、数据首发只本地。  
> **底栏只有 2 项**（2026-09-08 产品改口，废止 5 Tab）。  
> **Agent**：改导航或加页面前先读本文；与 PRD 冲突以 PRD 功能为准，以本文为壳与动线为准。

现状：APP-SHELL（T10-5）真机通过。2 Tab + 跟练全屏栈在用。课表/账号仍未实现。

## 1. 框架（2 Tab + 全屏训练栈）

对标 MLS 的是 **OLED、白胶囊、大图、浮动药丸底栏**，不是 5 个图标。底栏只留两项。

```
Root
├── 冷启动 / 游客或登录（PG-012，可跳过）
└── MainTabs（浮动药丸底栏，OLED，仅 2 项）
    ├── NAV-HOME  首页     PG-001
    │     页内分段：训练（PG-009）| 动作（PG-013）
    └── NAV-LOG   记录     PG-007
          页内分段：记录 | 我的（PG-008）
          └── 设置 PG-006（P2，从「我的」进入）

FullScreen（盖住 Tab）
├── PG-002 动作详情
├── PG-003 准备（仅跟练）
├── PG-004 训练中（相机；叠加层不改）
├── PG-005 本节/本动作总结
├── PG-011 计划模板
├── 组表编辑（FR-093，sheet）
└── 组间倒计时（FR-096，全屏）
```

| Tab | 底栏文案 | Phosphor | 页内 | 作用 |
|-----|----------|----------|------|------|
| NAV-HOME | 首页 | `House` | **动作 \| 训练**（白字下划线分段，MLS Eastern/Western） | 动作库 + 本节课组表 |
| NAV-LOG | 记录 | `Calendar` | **记录 \| 我的** | 日历/历史/PR + 账号 |

没有第三、第四、第五 Tab，**没有中间蓝圆 Plus**。开始训练在首页「训练」段。

规则：

- 底栏恰好 2 项。未选中 outline、选中 fill。
- PG-003 / PG-004 / 倒计时 **隐藏 Tab**。
- 单动作跟练也挂在一节课上（FR-093）。
- 不抄 MLS 商标、比分、Fantasy。

### 首页怎么同时放「训练」和「动作」

默认落在 **动作**：20 条 coachable + 自定义名（PG-013）。点卡片进 PG-002。

切到 **训练**：

- 有进行中的课：直接是组表（PG-009）。
- 无课：空态「新建训练」+ 可套用模板。详情主按钮「加入本节」（没有课则先新建再加入）；可跟练的再给「跟练」。

### 「记录」里怎么放「我的」

默认 **记录**：日历（PG-010）+ 课列表 + PR。  
切到 **我的**：登录/游客绑定/退出；P2 设置从这里进。

## 3. 动线

### 3.1 冷启动

```
打开 App
  ├─ 无本地身份 → PG-012（可「先去训练」= 游客）
  └─ 已有身份 → 首页（动作段）
```

### 3.2 记训（可不开相机）

```
首页 · 训练 → 新建或继续本节课
  → 切到「动作」选动作，或在课内「加动作」
  → 填组次重量 → 组间倒计时（可选）→ 结束课
  → 出现在「记录」
```

### 3.3 跟练

```
首页 · 动作 → 详情 → 跟练
  或 首页 · 训练 里某动作「跟练」
  （无进行中的课则先建一节）
  → 准备 → 相机 → 结束 → 改次数填重量 → 回到首页 · 训练
```

### 3.4 回看与账号

```
记录 · 记录 → 日历或课详情
记录 · 我的 → 登录 / 绑定
```

云同步 FR-101 不做。

## 4. 导航实现约定（编码时）

- React Navigation：`NativeStack` 包 **2** 个 `BottomTab`。
- 自定义浮动条（圆角 28、底 inset 12）。不要 5 槽、不要中间凸起按钮。
- 首页、记录用页内 `Segmented`（厚白下划线），不要再拆 Tab。
- 相机页 `gestureEnabled: false`。
- 课表状态进 `packages/core` 或 `packages/session`，禁止只活在 Screen `useState`。
