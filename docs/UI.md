# UI / UX 规格说明

> 供设计与开发共用。PRD 需求 ID 以 `UI-xxx` 引用本文件。  
> **Agent**：实现 M3/M4/M5 前必须先读本文 + `docs/design-tokens.md`（MU 模块产出）。

## 1. UI 分三层（避免混在一起做）

| 层级 | 名称 | 做什么 | 在哪个模块做 |
|------|------|--------|--------------|
| **L1** | 设计基础 | 设计令牌、线框图、组件清单、平台差异 | **MU**（M0 后、M3 前） |
| **L2** | 训练叠加层 | 摄像头上的骨骼、ghost、反馈条、站位引导 | **M3** |
| **L3** | 应用页面层 | 动作库、详情、准备、总结等标准页面 | **M4 / M5** |

```
M0 基建
  ├─→ M1 Core（无 UI）
  └─→ MU 设计基础 ──┬─→ M3 叠加层 UI
                    └─→ M4/M5 页面层 UI
```

**关键结论**：UI **不是**等到 M4 才考虑。  
- **MU** 在 M1 同期定调性和布局原则  
- **M3** 做最核心的「训练中」体验（用户 80% 时间所在）  
- **M4/M5** 做壳子和流程页

见 `docs/design-tokens.md`（MU 模块产出）。MVP 最小集：

### 2.1 语义色（与 FR-061 对齐）

| Token | 用途 | 默认值 |
|-------|------|--------|
| `--color-correct` | 关节正确 | `#22C55E` |
| `--color-warning` | 注意 | `#EAB308` |
| `--color-error` | 错误 | `#EF4444` |

| `--color-overlay-text` | 反馈条文字 | `#FFFFFF` |
| `--color-bg` | 页面背景 | `#0F172A` |
| `--color-surface` | 卡片 | `#1E293B` |
| `--color-primary` | 主按钮 | `#3B82F6` |

### 2.2 字体

| Token | 用途 | App | 小程序 |
|-------|------|-----|--------|
| `--font-title` | 页面标题 | 20sp bold | 18px bold |
| `--font-feedback` | 反馈条 | 18sp semibold | 16px semibold |
| `--font-body` | 正文 | 16sp | 14px |
| `--font-caption` | 辅助 | 14sp | 12px |

### 2.3 间距与圆角

| Token | 值 |
|-------|-----|
| `--space-xs` ~ `--space-xl` | 4 / 8 / 16 / 24 / 32 |

## 5. 平台 UI 差异

| 项 | App (RN) | 微信小程序 |
|----|----------|------------|
| 导航 | React Navigation stack | `wx.navigateTo` |
| 字体 | 系统默认 SF/Roboto | 微信默认字体 |
| 摄像头比例 | 全屏 `cover` | `camera` 组件固定比 |
| 底部安全区 | `SafeAreaView` | `env(safe-area-inset-bottom)` |
| 主按钮高度 | ≥48dp | ≥44px |

MVP：**结构一致，允许像素级差异**；颜色/字号走同一套 token。

## 6. 交互与动效（MVP）

| ID | 行为 | 说明 |
|----|------|------|
| UX-001 | 反馈条入场 | 错误时自上而下 slide-in，200ms |
| UX-002 | 关节变色 | 150ms 颜色过渡，避免闪烁 |
| UX-003 | Rep +1 | 数字 scale 1.2→1.0，300ms |
| UX-004 | 倒计时 | 每秒切换，最后 1 秒略放大 |
| UX-005 | 正确反馈 | 连续 correct 2s 可显示轻量「很好」 |

---

## 7. 无障碍（MVP 最低线）

- 反馈**必须有文字**（FR-063），不能仅靠颜色
- 按钮触控区 ≥44pt
- 总结页数据用文本而非纯图标
